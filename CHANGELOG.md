# Changelog

## 1.0.1 — full comfort and semantic-role pass

- Kept all 25 canonical colors unchanged.
- Added official UI role mappings and comfort guidelines.
- Audited every included terminal, desktop, shell, editor, reader,
  browser, launcher, notification, and monitoring port.
- Replaced persistent accent-filled selections with neutral selected
  surfaces where appropriate.
- Standardized taupe as the default focus and functional accent.
- Reduced continuous rainbow-like coloring in Waybar.
- Added complete GTK 3 and GTK 4 theme foundations.
- Expanded Qt role coverage.
- Added approved muted ANSI bright derivatives with preserved hue
  families.
- Removed Alacritty's nearly invisible custom dim-black mapping.
- Added semantic comfort validation and a cross-context visual QA asset.

- Locked the immutable 25-color canonical Limei palette.
- Standardized public attribution to harunnoir.
- Established a stable official ANSI 16 mapping.

- Added deterministic generation for mappings, previews, templates, and terminal ports.

- Separated canonical, mappings, and derived color layers.
- Added role-aware contrast reporting and repository validation.
- Added GitHub Actions CI.
