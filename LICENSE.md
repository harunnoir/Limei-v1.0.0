# Licensing

Limei uses two licenses because the palette and executable configuration code
are different kinds of work.

## Palette, names, documentation, and visual assets

Licensed under **Creative Commons Attribution-ShareAlike 4.0 International**
(`CC-BY-SA-4.0`). This covers the canonical colors, semantic descriptions,
documentation, previews, and visual assets.

Shared adaptations must provide appropriate attribution, indicate changes, and
use the same or a compatible share-alike license.

## Configuration ports, generators, validators, and templates

Licensed under **GNU General Public License version 3 or later**
(`GPL-3.0-or-later`). This covers software configuration ports, scripts,
generators, validators, and reusable code templates.

See the complete legal texts in [`LICENSES/`](./LICENSES/) and the preferred
credit wording in [`NOTICE.md`](./NOTICE.md).
