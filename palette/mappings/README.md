# Compatibility mappings

Mappings adapt the immutable Limei 25 palette to external color systems.

- `ansi16.json` and `ansi16.toml`: official stable ANSI mapping.
- `terminal-special.json`: background, foreground, cursor, and selection.
- `xterm256.json`: nearest fixed index for each canonical Limei color.

Mappings are generated and must not be edited directly.
