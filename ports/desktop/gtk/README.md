# Limei GTK

Colors based on the Limei palette by **harunnoir**.

Copy the `Limei` directory to:

```text
~/.local/share/themes/Limei
```

Select it with `nwg-look` or:

```bash
gsettings set org.gnome.desktop.interface gtk-theme 'Limei'
gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
```

The theme keeps selections and tabs neutral, uses taupe for focus, sage for
primary controls, green for progress, slate for links, lavender for visited
links, amber for warnings, and red for destructive states.
