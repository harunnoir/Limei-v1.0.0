# Manual visual QA

Open `limei-contexts.svg` and review it at normal display brightness.

Then test the real ports:

- terminal ANSI chart, selections, search, tabs, and dim text;
- GTK and Qt buttons, entries, tabs, menus, disabled text, and scrollbars;
- Waybar normal, warning, disconnected, muted, and critical states;
- Mako/SwayNC low, normal, and high urgency;
- Rofi/Wofi search, selected rows, and urgent entries;
- Helix comments, matching brackets, diagnostics, selections, and modes;
- Zathura/Sioyek document recoloring, highlights, and links;
- btop graphs and selected process rows;
- Chromium/Helium active and inactive tabs and omnibox.

The preview is a structural reference, not a replacement for application
testing.
